# Environment Variables Reference

Tài liệu liệt kê đầy đủ các biến môi trường được dùng trong dtgk-backend.

## Setup Instructions

1. Copy `.env-sample` to `.env`:
   ```bash
   cp .env-sample .env
   ```
2. Fill in required variables
3. For development, use default values provided in `.env-sample`

## Core Configuration

### Application Settings

| Variable | Type | Default | Description |
| --- | --- | --- | --- |
| `NODE_ENV` | string | `development` | Environment (development, staging, production) |
| `APP_NAME` | string | `dtgk-backend` | Application name |
| `APP_PORT` | number | `8080` | Server port |
| `API_BASE_URL` | string | `http://localhost:8080/api` | API base URL |

### Database Configuration

| Variable | Type | Default | Description |
| --- | --- | --- | --- |
| `DB_HOST` | string | `localhost` | PostgreSQL host |
| `DB_PORT` | number | `5432` | PostgreSQL port |
| `DB_NAME` | string | `dtgk_dev` | Database name |
| `DB_USER` | string | `postgres` | Database user |
| `DB_PASSWORD` | string | `1234` | Database password |
| `DB_DIALECT` | string | `postgres` | Database dialect |

### Redis Configuration

| Variable | Type | Default | Description |
| --- | --- | --- | --- |
| `REDIS_HOST` | string | `localhost` | Redis host |
| `REDIS_PORT` | number | `6379` | Redis port |
| `REDIS_PASSWORD` | string | \`\` | Redis password (optional) |
| `REDIS_DB` | number | `0` | Redis database number |

### Authentication & Security

| Variable | Type | Required | Description |
| --- | --- | --- | --- |
| `JWT_SECRET` | string | Yes | Secret key for signing JWT tokens |
| `JWT_EXPIRATION` | string | No | Token expiration time (default: 8h) |
| `REFRESH_TOKEN_SECRET` | string | Yes | Secret for refresh tokens |
| `REFRESH_TOKEN_EXPIRATION` | string | No | Refresh token expiration (default: 30d) |
| `SECURITY_ENCRYPT` | boolean | Yes | Enable encryption for keyProxy |
| `VECTOR` | string | Yes | Encryption vector |
| `ALGORITHM` | string | Yes | Encryption algorithm (aes-256-cbc) |

**⚠️ WARNING:** Missing SECURITY\_ENCRYPT, VECTOR, or ALGORITHM will cause all requests through keyProxy to fail with 400 Invalid API Key.

### IP Configuration

| Variable | Type | Format | Description |
| --- | --- | --- | --- |
| `IP_GK` | string | JSON array | Whitelisted IPs for Gateway (e.g., `["127.0.0.1","::1"]`) |
| `ALLOWED_ORIGINS` | string | Comma-separated | CORS allowed origins |

**⚠️ WARNING:** IP\_GK must be valid JSON array format. Invalid format will crash the app on startup.

## Example .env File

```bash
# Application
NODE_ENV=development
APP_NAME=dtgk-backend
APP_PORT=8080

# Database
DB_HOST=localhost
DB_PORT=5432
DB_NAME=dtgk_dev
DB_USER=postgres
DB_PASSWORD=1234

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379

# JWT
JWT_SECRET=your-super-secret-key-change-in-production
REFRESH_TOKEN_SECRET=your-refresh-secret-key

# Security
SECURITY_ENCRYPT=true
VECTOR=your-encryption-vector
ALGORITHM=aes-256-cbc

# IP Configuration
IP_GK=["127.0.0.1","::1"]

# Logging
LOG_LEVEL=info
```

## Environment-Specific Values

### Development

- `NODE_ENV=development`
- `LOG_LEVEL=debug`
- `OTEL_ENABLED=false`

### Staging

- `NODE_ENV=staging`
- `LOG_LEVEL=info`
- `OTEL_ENABLED=true`

### Production

- `NODE_ENV=production`
- `LOG_LEVEL=warn`
- `OTEL_ENABLED=true`
- All secrets from secure vault
- No default values for sensitive data
